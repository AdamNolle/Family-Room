# Family Room site

Static marketing site for the in-development Mantelpiece prototype. Open `index.html` locally or serve this directory with any static file server. No build step or external assets are required.

## Design and claim contract

- Visual premise: a sunlit family album, using the app's cream, ink, and terracotta tokens from `Sources/Shared/DesignSystem.swift`.
- Site art is an original HTML/CSS illustration based on the current SwiftUI Mantelpiece views and the hardcoded sample family/moments in `AppViewModel.swift`. It is labeled as an illustration, not a recorded app screenshot.
- Current source supports home, sample person selection, memory detail, and adaptive iPhone/iPad/Mac navigation. The feature copy is limited to those surfaces.
- The source currently returns dummy face IDs, has no working story export, and has no demonstrated CloudKit collaboration. Those features are explicitly identified as development ideas.
- All shipped files are original project code. The site uses system fonts and no third-party imagery, audio, or scripts.

There is no deployment configuration or public domain in this repository. Add a hosting route only after the owner selects one, then verify the deployed URL before adding it to the GitHub repository's homepage or README.
